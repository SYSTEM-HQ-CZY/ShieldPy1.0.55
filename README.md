# ShieldPy 玄盾卫士 v1.0.55

纯 Python 实现的轻量图形界面杀毒软件。哈希特征库 + 启发式检测 + 隔离区 + 主动防御，
覆盖 Python 能力范围内的全套杀软功能。

**v1.0.55 更新**：
① 修复扫描页"隔离选中/删除选中/信任选中"三个按钮无法显示的问题；
② 主动防御能力加强 —— 实时防护**默认开启全盘监控**（无需选文件夹）、
发现威胁可自动隔离/删除、新增自启动项与 hosts 文件保护、新增**防御中心**页面；
③ 修复扫描进度条来回跳动（并发扫描冲突 + 进度单调保护）；
④ 主题深浅色切换改为弹窗提示重启生效（不再卡死）；
⑤ **系统托盘后台常驻**，关闭窗口最小化到托盘，托盘菜单可恢复界面/暂停-恢复防护/退出。

**v1.0.2 更新**：① 大幅降低误报（启发式收紧 + 风险分级 + 良性豁免，实测 399 个真实系统脚本 0 误报）；
② 修复全盘扫描 CPU 占用过高（多线程并行 + 可调性能节流，默认 CPU 从满载降至约 43%，可再降到 24%）。

## 运行环境

- Python **3.6 及以上**
- 需要 tkinter（Python 官方 Windows 版自带）
- 增强依赖（打包 exe 已内置）：`watchdog`（全盘实时监控事件驱动）、`pystray` + `Pillow`（系统托盘）
  - 源码方式运行且未装这些时，全盘监控退化为关键目录轮询、无系统托盘

## 快速开始

```bat
cd ShieldPy
D:\python\python.exe main.py
```

或直接双击 `启动玄盾卫士.bat`（脚本内置了启动命令）。

### 30 秒自测流程

1. 先运行一次样本生成，造出"病毒"和"干净文件"各一批：

   ```bat
   D:\python\python.exe scripts\make_samples.py
   ```

2. 在软件里进入 **自定义扫描** → 点 **"使用测试样本目录"** → **开始扫描**。

3. 预期结果：

   | 文件 | 检测方式 | 结果 |
   |---|---|---|
   | `eicar.com` | 哈希特征库 | 检出（EICAR 测试样本） |
   | `fake_malware.vbs` | 启发式 | 检出 |
   | `fake_dropper.bat` | 启发式 | 检出 |
   | `clean_hello.py` / `clean_note.txt` | — | 判定安全（无误报） |

4. 选中检出项 → **隔离** → 到 **隔离区** 可恢复或彻底删除。

> `eicar.com` 是杀毒软件行业通用的**标准测试文件**，本身完全无害，
> 专门用来验证杀软是否正常工作（真实杀软也能查到这个样本）。

## 检测原理简析

1. **特征码（哈希）检测**：先算文件 MD5/SHA256，与特征库比对。快、准、但只能查已知样本。
2. **启发式检测**：对 VBS / PS1 / BAT / JS / HTA 等脚本做内容分析，
   对"下载执行 / 写自启动 / 隐藏执行 / 关闭杀软 / 编码混淆"等恶意行为模式打分。
   **v1.0.2 起**：需高分(≥5)或(≥4 分且命中≥2 类行为)才判"恶意"，并叠加良性豁免与风险分级，
   显著减少正常脚本误报；高熵不再独立触发判定。
3. **加壳检测**：检查 PE 文件头部是否存在 UPX 等加壳特征（现降级为低风险提示，因合法软件也可能加壳）。
4. **混淆检测**：高熵内容作为恶意判定的加成项。

真实世界杀软（如卡巴斯基）的核心机制也是这四层的工程化组合：
特征库 + 启发式/行为分析 + 脱壳/沙箱 + 云查杀。本项目是它们的简化实现。

## 安全说明

- 本项目用于**学习、研究、防御性用途**。它只是一个轻量演示级工具，
  **不能替代**卡巴斯基、Windows Defender 等商业杀软来保护你的重要系统。
- 扫描判定基于内置的小型特征库与启发式规则，**可能误报**。
  对于重要文件，请优先使用"隔离"而非"删除"，确认无害后再恢复或加入白名单。
- EICAR 测试样本是行业公认的安全测试文件，可放心生成和使用。
